# Brand assets

- `palatial-white.svg`: Palatial's supplied white wordmark, preserved from the Palatial documentation brand assets.
- `nvidia-white.svg`: NVIDIA's green eye and white wordmark, preserved from [NVIDIA's BioNeMo documentation](https://github.com/NVIDIA/bionemo-framework/blob/main/docs/docs/assets/images/logo-white.svg). Display follows the [NVIDIA brand guidance](https://www.nvidia.com/en-gb/about-nvidia/legal-info/logo-brand-usage/), retaining the original colors, proportions, and clear space.
