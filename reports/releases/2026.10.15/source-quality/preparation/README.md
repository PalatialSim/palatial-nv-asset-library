# Source-quality corrections — qualification in progress

A full audit of the 1,013 released assets identified source-quality corrections for 221 assets: undefined authored normals, exactly zero-area faces, and impossible explicit mass properties. The proposed revisions repair 3,188 undefined normals, remove 35,164 zero-area faces, and use standard geometry-derived automatic mass properties on 20 rigid bodies. Automatic mass properties are modeling approximations, not measurements.

All point coordinates, surviving surfaces and UVs, texture bytes, material relationships, transforms, mass and density values, collision occupied surfaces and joint definitions are preserved. [The paired invariant checks](source-invariants.json) and [exact repair records](repairs.json) bind each change to its original and corrected source hash. [Metadata inspections](metadata-inspections.json) preserve historical runtime evidence under its original source hash; they do not qualify a changed source. [The legacy-folder check](legacy-source-alias-preflight.json) verifies the exact existing dependency bytes before any alias replacement.

This is a preparation snapshot, **not a completed correction release or NVIDIA approval**. [Qualification progress](qualification-progress.json) lists only actual completed corrected-source packages with immutable reports. Each correction requires the full unchanged stock validation and applicable benchmarks on both configured engines, complete packaging, immutable file verification and independently hashed raw archives. Raw failed results remain failed and disclosed. These PhysX-authored assets do not claim Newton physics qualification.

The original batch downloads and public catalog remain the previous released revisions until the coherent source, metadata and catalog update is verified. Earlier packages and failed attempts remain immutable. The existing SimReady Central submission is [PR #47](https://github.com/NVIDIA-Omniverse/simready-central/pull/47); no second submission PR is being created.
